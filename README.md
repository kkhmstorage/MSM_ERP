# 🕌 Muhyissunna Secondary Madrasa ERP

> **MSM ERP** — A comprehensive school management system for Muhyissunna Secondary Madrasa.

## ✨ Features

- 📊 **Dashboard** — Real-time statistics and overview
- 👨‍🎓 **Student Management** — Enrollment, profiles, and records
- 🏫 **Class Management** — Sections, subjects, and timetables  
- 📝 **Attendance Tracking** — Daily attendance with reports
- 📋 **Exam & Results** — Mark entry and result generation
- 💰 **Fee Management** — Fee collection and tracking
- 📚 **Library System** — Book management and issue tracking
- 👨‍🏫 **Staff Management** — Teacher and staff records
- 📄 **Reports & Certificates** — Printable reports and certificates
- ☁️ **Cloud Database** — Powered by Firebase Realtime Database

## 🚀 Live Demo

🔗 [https://kkhmstorage.github.io/MSM_ERP/](https://kkhmstorage.github.io/MSM_ERP/)

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Styling:** Tailwind CSS, Font Awesome Icons
- **Database:** Firebase Realtime Database
- **Hosting:** GitHub Pages

## 📱 PWA Support

This app supports Progressive Web App (PWA) features and can be installed on mobile devices.
